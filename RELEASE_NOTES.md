# Tape Fiasco 2 v2.0.0.660

This release includes the latest v2.0.0.660 build and, on macOS and Windows,
the previous v2.0.0.563 build as a stable fallback.

Highlights:

- Four new effects: Aether, Clang, Orbit, and Tremor
- Expanded Perform macro and X/Y modulation targets
- Tempo-synced rates and additional stereo-link controls
- 27 new Therapeutic Fiasco factory presets
- Linux VST3 support
