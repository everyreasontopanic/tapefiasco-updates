# Tape Fiasco 2 v2.0.0.828

This release contains the current Tape Fiasco 2 desktop plug-ins:

- macOS Universal AU and VST3 (`arm64` and `x86_64`) in a double-click `.pkg`
  installer, signed with Developer ID, notarized by Apple, and stapled for
  offline validation
- Windows x64 VST3 in an unsigned `.exe` installer, with the raw VST3 bundle
  also included for manual installation
- Linux x86_64 VST3

The macOS and Windows downloads also include v2.0.0.660 as the stable fallback.
Install v2.0.0.828 unless you specifically need to roll back.

Highlights:

- Fixed host automation of Perform MACRO 1-4 stopping when the plug-in editor
  window was closed
- Macro assignments, curves, mode filtering, synced Stutter routing, linked
  parameters, and Animate targets now keep working with or without an open UI

Choose the ZIP for your operating system below. No GitHub account is required.
